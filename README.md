# DialogSpyBot

Telegram-бот на **aiogram 3.x**, который ведёт журнал сообщений: сохраняет
всё входящее в SQLite, отслеживает правки (хранит старую и новую версию),
позволяет помечать удалённые сообщения и искать по истории.

## Возможности

- Сохранение каждого входящего сообщения: `chat_id`, `user_id`, `username`,
  текст, дата/время, `message_id`.
- Отслеживание редактирования сообщений с полной историей версий.
- Пометка сообщений как удалённых.
- Команды `/history`, `/deleted`, поиск по тексту и по пользователю.
- Доступ к командам — только для администраторов из `ADMIN_IDS`.
- Асинхронная архитектура (SQLAlchemy 2.0 async + aiosqlite).
- Автоматическое создание таблиц при старте, логирование, конфиг через `.env`.

## Структура

```
bot.py            — запуск
config/           — настройки из .env (pydantic-settings)
models/           — ORM-модели (Message, MessageEdit)
database/         — движок, фабрика сессий, CRUD
services/         — бизнес-логика и форматирование вывода
handlers/         — роутеры команд и перехвата сообщений
```

## Запуск

### Docker (рекомендуется)

```bash
cp .env.example .env       # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
docker compose logs -f
```

### Локально

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env       # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

## Команды

| Команда | Описание |
|---|---|
| `/history [N]` | последние N сообщений текущего чата |
| `/history_all [N]` | последние N сообщений по всем чатам |
| `/deleted [N]` | удалённые сообщения |
| `/search <текст>` | поиск по подстроке в тексте |
| `/user <@username\|id>` | сообщения конкретного пользователя |
| `/info <message_id>` | карточка сообщения с историей правок |
| `/markdeleted <message_id>` | пометить сообщение удалённым (или ответом на него) |

## Важно про удаление сообщений

Telegram **Bot API не присылает событий об удалении** сообщений
пользователями (это доступно только клиентам MTProto / userbot’ам).
Поэтому удаление здесь отмечается **вручную** администратором командой
`/markdeleted`. Сам текст уже сохранён в БД заранее, поэтому остаётся
доступен даже после удаления в Telegram.

## Сбор сообщений в группах

Чтобы бот видел все сообщения группы (а не только команды), отключите
**Group Privacy** у бота через @BotFather (`/setprivacy` → `Disable`) и
добавьте бота в чат. Для каналов добавьте его администратором.
